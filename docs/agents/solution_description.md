# solution description

Enhances the solution design description of a ticket with architecture detail and posts an assessment of the result.

## Parameters

Configured via `customParams` in the agent JSON or the project `.dmtools/config.js`.

- `checkOpenPR` — check open pr.
- `childQuestions` — child questions.
- `contexts` — contexts.
- `fields` — fields.
- `jql` — jql.
- `parentContextFetch` — parent context fetch.
