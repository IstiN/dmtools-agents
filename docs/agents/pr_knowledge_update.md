# pr knowledge update

CliAgent that curates the review knowledge base: distills merged PR outcomes into reusable review guidance and pushes the update.

## Parameters

Configured via `customParams` in the agent JSON or the project `.dmtools/config.js`.

- `diffText` — diff text.
- `discussionsMarkdown` — discussions markdown.
- `knowledgeDir` — knowledge dir.
- `prNumber` — pr number.
- `prTitle` — pr title.
- `prUrl` — pr url.
- `ticket` — ticket.
