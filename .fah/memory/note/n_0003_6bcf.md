# Note: n_0003_6bcf

In dmtools-agents, `js/agentDocGenerator.js` `collectSideEffects()` matches `/git push|git checkout|git merge|git rebase/g` against RAW source including comments, so any comment mentioning those literals publishes them as agent side effects in docs/agents/generated/*.md and fails the `docs-freshness` CI job (regenerate + `git diff --exit-code -- docs/agents/generated`). When writing comments in js/ files scanned by agent configs (timerJSAction/preCliJSAction/postJSAction sources), never write the literal "git merge"/"git rebase" etc. unless the code really does it — reword (e.g. "merge of origin/main"). Verify with `node js/agentDocGenerator.js` → expect empty docs diff.
