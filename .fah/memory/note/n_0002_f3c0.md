# Note: n_0002_f3c0

In dmtools-agents, .github/workflows/agent-pack-release.yml contains a REAL secret on the origin_url line (x-access-token) that every file-read/grep output redacts to "[REDACTED:Connection String Password]". Exact-match edits spanning that line always fail and hashline patches must not include it — split edits around the origin_url line. Also: the session has a WIP auto-save that commits the working tree periodically ("gh-690 WIP auto-save ..."), so new files can become tracked mid-task and git status/diffs must be interpreted against the latest auto-save commit.
