# Note: n_0002_f3c0

In dmtools-agents, .github/workflows/agent-pack-release.yml builds its origin_url by shell-expanding the step's PUSH_TOKEN env (a secrets.* workflow secret): the `origin_url="https://x-access-token:${PUSH_TOKEN}@github.com/…"` line embeds ${PUSH_TOKEN}, and tooling redacts that line to "[REDACTED:Connection String Password]" — a scanner false positive on the interpolation, NOT a literal committed secret. Exact-match edits spanning that line always fail and hashline patches must not include it — split edits around the origin_url line. Also: the session has a WIP auto-save that commits the working tree periodically ("gh-690 WIP auto-save ..."), so new files can become tracked mid-task and git status/diffs must be interpreted against the latest auto-save commit.
