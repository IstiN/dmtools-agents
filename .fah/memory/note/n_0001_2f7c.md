# Note: n_0001_2f7c

The dmtools development-agent loop auto-commits the working tree every 5 minutes (timerAutoCommitAndSave.js, story_development.json) as "gh-<key> WIP auto-save" commits on the PR branch. Any scratch files/dirs left in the repo during a session (test copies, probe scripts, .dmtools runtime logs) get committed silently — clean them up (git rm --cached + rm, plus .gitignore patterns for runtime artifacts) before finishing, since the branch tree state is what the final PR ships.
