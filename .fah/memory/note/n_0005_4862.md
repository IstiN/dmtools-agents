# Note: n_0005_4862

Local replication of the dmtools-agents CRAP quality gate: npm i github:IstiN/crap4js + nyc@17 to /tmp/tools; nyc instrument repo → /tmp/inst (before creating any agents symlink); ln -sfn /tmp/inst /tmp/inst/agents; rsync non-js files; run node ci/run_with_coverage.js from /tmp/inst with the run_all.json testFiles (its known ~mock-gap failures must not block coverage collection); then run crap4js with analysis root = the original (non-instrumented) repo checkout — coverage-final.json keys are absolute nyc-baked source paths (they embed the checkout prefix of the machine that ran nyc), so the analysis root must equal that checkout prefix or every function shows N/A and the ratchet is vacuous ("570 removed"). Baseline: gh release download crap-baseline --repo IstiN/dmtools-agents. Known environment artifact: js/sm/sources/githubSource.js::matchesGuards measures 93.5 locally vs 90.4 in the released baseline — reproducible on unmodified origin/main, so a local 1-regression report on that function is drift, not a code regression.
