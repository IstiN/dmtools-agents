# CodeGraph-First Investigation Rule

Before inspecting `testing/` or any source file with `grep`, `find`, `cat`, or `sed`, start with a targeted `codegraph query "<SymbolOrHelperName>"` using 2–5 concrete code identifiers (class, method, page object, endpoint, or package) from the ticket or PR diff — **never include the ticket key or generic process phrases**. Follow with at most one `codegraph context "<2-5 code identifiers>" -n 10 --no-code` (and at most one `codegraph explore`), then use `codegraph node`, `codegraph callers`, and `codegraph callees` before opening files directly. Do not re-run reworded synonym queries.
